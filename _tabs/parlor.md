# Parlor

A native macOS, peer-to-peer remote **pair-programming** tool. The host shares one selected application window; the remote sees it live, gets an independent virtual cursor, can click/type/scroll into it, and optionally talk over audio. The host keeps full control of the rest of their Mac.

> Share one window. Work together naturally. Keep the rest of the Mac under the host's control.

[Visit the Parlor website](https://lasori.github.io/Parlor-page/)

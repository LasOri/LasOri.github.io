# First Try

A native macOS visual-context companion. Record one browser window, select confusing screen content, and get an answer grounded in relevant recorded history. It keeps capture, OCR, indexing, and retrieval local; inference can use either a local model or an explicitly configured remote provider.

> See it. Get it. Keep your context close.

[Visit the First Try website](https://lasori.github.io/First-Try-page/)
